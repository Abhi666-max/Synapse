# Synapse: Neon Override

**LevelUp Game Hackathon 2026 Submission**

## 🎮 Game Concept
Synapse: Neon Override is a high-octane, 3D web-based survival racer built to deliver a AAA console-quality experience directly in the browser. Set within a collapsing cyberpunk neural network, the player controls a hyper-agile neon hover-vehicle racing against time and procedurally generated obstacles.

## 🚀 Features
- **True 3D Gameplay:** Built with Three.js and React Three Fiber.
- **Realistic Physics:** Powered by the Rapier 3D engine for buttery-smooth collisions and dodging.
- **Time Dilation Mechanic:** Press `Spacebar` to slow down time, allowing impossibly tight drifts to survive narrow gaps.
- **Premium Aesthetics:** Custom GLSL shaders provide bloom, chromatic aberration, and neon visual effects.
- **Procedural Generation:** The obstacle course is endlessly generated, meaning no two runs are identical.
- **Glassmorphism UI:** Built with Framer Motion and Tailwind CSS for that expensive, modern SaaS-level interface.

## 🛠️ Technology Stack
- **Framework:** React.js (Vite)
- **3D Engine:** Three.js, `@react-three/fiber`, `@react-three/drei`
- **Physics:** `@react-three/rapier`
- **Post-Processing:** `@react-three/postprocessing`
- **UI/UX:** Tailwind CSS, Framer Motion
- **State Management:** Zustand

## 🕹️ Controls
- **A / Left Arrow:** Dodge Left
- **D / Right Arrow:** Dodge Right
- **Spacebar:** Activate Time Dilation (Slow-Mo)

## 📦 Installation & Setup
To run this project locally:

1. Clone this repository.
2. Ensure you have Node.js installed.
3. Run `npm install` to install dependencies.
4. Run `npm run dev` to start the local development server.
5. Open `http://localhost:5173` in your browser.
